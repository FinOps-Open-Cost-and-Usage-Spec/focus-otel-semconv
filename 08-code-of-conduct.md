# Code of Conduct

This Working Group follows the **Contributor Covenant Code of Conduct** adopted by the Community Specification project. The authoritative text is published there:

- [Code of Conduct, Community Specification V1.1](https://github.com/CommunitySpecification/Community_Specification/blob/V1.1/8._Code_of_Conduct.md)

This repository does not keep a copy of that document, so there is only one authoritative version.

To report a concern, contact the people listed in [Notices](03-notices.md#code-of-conduct). Do not raise Code of Conduct concerns in a public issue.
